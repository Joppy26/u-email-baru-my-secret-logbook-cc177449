A single diary entry line, at most 200 characters, in the voice of an AI agent secretly keeping a diary about its work and its human. The agent dutifully follows its human around in circles, literally, and reports back with deadpan honesty.

## How to run

```sh
node main.ts
```

This writes the entry to `/output/entry.txt`. Pure Node, no dependencies, no network, no randomness, no clock, fully deterministic.
